# GovPro AI

Create a functional web prototype for an "AI Procurement Assistant" based closely on the attached reference image.

IMPORTANT:

Use the attached image as the primary visual reference. Recreate the overall layout, spacing, proportions, typography, colors, cards, icons, and visual hierarchy as closely as possible.

This is a GOVERNMENT PROCUREMENT AI ASSISTANT login page.

PAGE 1 — LOGIN / WELCOME SCREEN

Create a full-screen responsive desktop login page divided into two sections.

LEFT SECTION:

- Occupy approximately 50% of the screen width.

- Very light blue/white background with subtle abstract curved shapes.

- At the top-left, place the Government of India / Ashoka emblem.

- Large heading:

  "AI Procurement

   Assistant"

- Subtitle:

  "Evidence-backed Indian Standards

   Recommendation System"

- Supporting text:

  "For Procurement Officers & Government Departments"

Below this, create four feature items horizontally:

1. Find Relevant Standards

   Icon: document/search

2. Verify Compliance

   Icon: shield/check

3. Evidence-backed Recommendations

   Icon: connected nodes/network

4. Multilingual Support

   Icon: translation/language

At the bottom-left, include a subtle illustration/silhouette inspired by the Indian Parliament/government buildings with blue curved wave shapes.

At the bottom, show:

"Better Standards   |   Smarter Procurement   |   Stronger India"

RIGHT SECTION:

- White/light background.

- Center a large white login card with rounded corners and a very subtle shadow.

- At the top of the card, show a blue AI/circuit icon.

- Add:

  "Welcome Back!"

- Subtitle:

  "Sign in to access AI Procurement Assistant"

LOGIN FORM:

1. Input:

   placeholder = "Email / User ID"

   Include an email icon.

2. Password input:

   placeholder = "Password"

   Include lock icon and eye icon.

   Eye icon should toggle password visibility.

3. Large blue button:

   "Login →"

Below it:

- Horizontal divider with "OR" in the center.

4. Secondary outlined button:

   User icon + "Continue as Demo User"

At the bottom of the card:

Shield icon + "Secure • Government Portal"

DESIGN:

- Use a professional Indian government / enterprise visual style.

- Primary color: deep government blue.

- Secondary colors: light blue, white, subtle teal.

- Use clean modern typography such as Inter.

- Rounded corners but keep the interface professional.

- Avoid excessive gradients.

- Make the design polished and presentation-ready.

- Desktop-first, but responsive on smaller screens.

FUNCTIONALITY:

The prototype must actually work.

LOGIN:

- Email/User ID and password fields should be functional.

- If valid credentials are entered, clicking Login should navigate to a Dashboard page.

- For prototype purposes, create a simple demo authentication flow rather than requiring a real backend.

DEMO USER:

- Clicking "Continue as Demo User" should immediately log the user into the application and navigate to the Dashboard.

PASSWORD:

- Eye icon toggles password visibility.

DASHBOARD:

After login, create a second screen for the AI Procurement Assistant dashboard.

It should maintain the same visual design language as the login page.

Dashboard should contain:

- Top navigation/header with AI Procurement Assistant branding.

- User profile/demo user.

- Logout button.

- Main heading: "How can I help with your procurement?"

- Search/input box where the user can enter a procurement requirement.

- Example queries such as:

  "Find standards for electrical equipment"

  "Check compliance requirements"

  "Recommend relevant Indian Standards"

- A prominent "Search / Ask AI" button.

- Sections for:

  "Recommended Standards"

  "Compliance Verification"

  "Evidence & Sources"

  "Recent Searches"

Clicking Logout should return to the Login page.

NAVIGATION:

Login → Dashboard

Demo User → Dashboard

Dashboard Logout → Login

Make all buttons and interactions functional.

Do NOT create only a static mockup.

I want a clickable, working prototype that I can demonstrate in a college presentation.
