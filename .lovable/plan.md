# AI Procurement Assistant prototype

## Build
- Recreate the reference login screen as a responsive two-panel government portal using the supplied image only as visual reference.
- Add the Ashoka-style emblem treatment, procurement features, Parliament-inspired silhouette, layered blue waves, and secure login card.
- Implement email/user ID and password validation, password visibility, demo access, and clear feedback states.
- Add a separate dashboard with branding, user status, logout, procurement question entry, example prompts, results sections, and recent searches.
- Keep authentication intentionally local and temporary for presentation use; refreshing or logging out returns to the sign-in flow.

## Technical details
- Use TanStack Router routes for `/` and `/dashboard`.
- Keep visual tokens and shared styling in the project design system.
- Use Lucide icons and CSS artwork so no external backend or image dependency is required.
- Add unique page metadata and verify desktop/mobile layouts plus the complete login/search/logout flow.
